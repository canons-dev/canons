# 第三方技能（canons）

- **V1** 第三方技能是供应链依赖：正文被当作指令执行，附带脚本可能被当作代码运行。默认不信任。
- **V2** 先放进 `tmp/`，不要直接放进可能被客户端自动加载的技能目录。读完 `SKILL.md` 和每个脚本；有网络外发、运行下载来的代码、或无明确理由读取密钥和环境变量的，一律拒绝。
- **V3** 把审计过的版本 vendor 进仓库，在 lock（例如 `skills-lock.json`）里记录来源和内容 hash，并把 `description` 收窄到本项目真实的触发场景。
- **V4** 上游正文与本地改动分开存放；绝不重算上游 hash 来掩盖本地修改。升级要有意为之，并重新审计。
