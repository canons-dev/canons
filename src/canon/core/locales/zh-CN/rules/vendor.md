# 第三方技能（canons）

- **V1** 第三方技能是供应链依赖：正文被当作指令执行，附带脚本可能被当作代码运行。默认不信任。
- **V2** 审计完成之前，技能不能被任何客户端加载：先放在客户端不会自动加载的地方（例如 `tmp/`）。读完 `SKILL.md` 和每个脚本；有网络外发、运行下载来的代码、或无明确理由读取密钥和环境变量的，一律拒绝。
- **V3** 进仓库的必须是审计过的那一版，并且以后能核对：vendor 进仓库，在 lock（例如 `skills-lock.json`）里记录来源和内容 hash。`description` 收窄到本项目真实的触发场景，免得技能在无关任务里被加载。
- **V4** 上游正文与本地改动分开存放；绝不重算上游 hash 来掩盖本地修改。升级要有意为之，并重新审计。
